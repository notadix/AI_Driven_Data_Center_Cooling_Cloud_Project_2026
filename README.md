## Problem Statement
Data centers consume a significant amount of global electricity, with cooling systems accounting for 30% to 40% of overall facility power usage. Modern high-density compute racks generated by intensive workloads increase thermal density, making it difficult to maintain safe operating temperatures while avoiding excessive energy consumption. 

Existing solutions generally fall into two categories:
1. High-fidelity physics and CFD models that accurately simulate thermal dynamics but are computationally expensive and run offline, making them unsuitable for real-time control.
2. Machine learning and reinforcement learning controllers that adjust setpoints in real time but lack physical grounding, lack hard safety guarantees to prevent thermal SLA breaches, and focus only on energy or PUE without considering grid carbon intensity or water consumption.

Additionally, most existing studies are evaluated on single-site offline testbeds rather than scalable cloud infrastructure. An integrated framework is needed to combine physics-informed surrogate modeling, safe reinforcement learning control, multi-objective sustainability optimization, and cloud-based deployment.

## Objectives
1. **Digital Twin Integration**: Build a real-time digital twin of a data center cooling infrastructure using AWS IoT TwinMaker and SiteWise to synchronize live sensor telemetry and setpoint actuation.
2. **Predictive Thermal Surrogate**: Train a Fourier Neural Operator (FNO) thermal surrogate calibrated against CFD simulations and operational telemetry to forecast rack and hall temperatures with low latency.
3. **Safety-Aware Reinforcement Learning**: Implement a constrained reinforcement learning agent (Safe PPO) trained within the digital twin environment to lower cooling energy usage while maintaining strict thermal SLA boundaries (18°C – 27°C IT inlet temperature).
4. **Carbon and Sustainability Optimization**: Incorporate a multi-objective reward function incorporating real-time grid carbon intensity (gCO2e/kWh) and water usage effectiveness (WUE) to shift workloads and cooling operations.
5. **Cloud Deployment & Scalability**: Deploy the pipeline on AWS using IoT Core, Timestream, SageMaker, and EKS to support automated retraining, drift detection, and multi-facility transfer learning.
6. **Explainability**: Integrate SHAP feature attributions and policy distillation to provide interpretable control rationales for facility operators via a visual dashboard.

## Proposed Architecture/Framework
The framework consists of five main layers operating in a closed loop:

1. **Telemetry & Physical Interface Layer**: Industrial RTD temperature sensors, flow meters, and power meters connected via Modbus/BACnet edge gateways to AWS IoT Core over MQTT.
2. **Digital Twin & Physics Surrogate Layer**: AWS IoT SiteWise and TwinMaker binding sensor telemetry to a fast Fourier Neural Operator (FNO) surrogate for real-time state estimation and temperature forecasting.
3. **Control & Sustainability Layer**: A constrained PPO agent evaluating thermal states, workload predictions, and grid carbon signals to calculate optimal supply temperatures, pump speeds, and valve splits.
4. **Cloud Pipeline & MLOps Layer**: AWS Step Functions orchestrating closed-loop ingestion, SageMaker hosting model training and inference endpoints, and EventBridge handling automated retraining upon thermal drift.
5. **Operator Dashboard Layer**: A web dashboard displaying 3D thermal heatmaps, real-time PUE and carbon metrics, SHAP explanations, and manual control overrides.

## Dataset Details
- **Primary Dataset**: Energy dataset of the Frontier supercomputer (`Frontier2023`).
  - **Source**: Oak Ridge National Laboratory (ORNL) / Nature Scientific Data (Figshare DOI: 10.6084/m9.figshare.24391240).
  - **Details**: 1 full year (2023) of liquid cooling telemetry (~52,560 records at 10-minute resolution).
  - **Features**: Coolant supply/return temperatures, flow rates, CDU heat loads, facility power, IT power, PUE.
  - **License**: Creative Commons Attribution (CC BY 4.0).
- **Simulation Sandbox**: ExaDigiT / LC-Opt Modelica physics engine used as the Gymnasium environment for RL policy training.
- **Auxiliary Data**: ASHRAE climate zone weather data and real-time grid carbon intensity feeds (WattTime / Electricity Maps).
